# Template project for Azure Functions

[Template](https://usausa.github.io/template/) project for Azure Functions.

# ✅ Implement

| Category | Feature |
| --- | --- |
| Function | HTTP trigger / Queue trigger (Storage Queues) / Timer trigger / Binding generator (AzureFunctionsExtension) / Middleware (exception logging) |
| API | CRUD (`/api/data`) / Paging (limit, offset) / Validation (DataAnnotations) / JSON (camelCase) |
| Data | SQL Server (Smart.Data.Accessor, SQL files) / Mapper (Smart.Mapper) |
| Observability | Application Insights / Logging |
| Test | Unit tests (xUnit v3, MTP) / Handler tests / Code coverage (Cobertura) |
